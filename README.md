# AlphaWire

AlphaWire is an AI-powered market news daily briefing bot for Telegram.

## Bots

- `bots/news_bot.py` generates a daily market briefing with OpenAI web search and posts it to Telegram.
- `bots/review_bot.py` verifies that today's briefing was posted and replies with a short review comment.

## Local Setup

1. Create a Telegram bot with BotFather and add it to your target group.
2. Copy `.env.example` to `.env`.
3. Fill in the required environment variables.
4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Run the news bot:

```bash
python bots/news_bot.py
```

If `OPENAI_API_KEY` is empty, the bot sends a sample briefing so Telegram delivery can be tested locally.

## Environment Variables

- `TELEGRAM_BOT_TOKEN`: Telegram bot token from BotFather.
- `REVIEW_TELEGRAM_BOT_TOKEN`: Token for the review bot. If omitted locally, `TELEGRAM_BOT_TOKEN` is used.
- `TELEGRAM_CHAT_ID`: Target chat ID or channel/group username.
- `OPENAI_API_KEY`: OpenAI API key.
- `OPENAI_MODEL`: OpenAI model used for live briefing generation, for example `gpt-5.4-mini`.
- `ALPHAWIRE_USE_LIVE_OPENAI`: Set to `true` only when you want to call OpenAI. Defaults to sample briefing/review content for bot delivery testing.
- `NEWS_BOT_USERNAME`: Optional Telegram username for best-effort update scanning.

## Review Bot Note

Telegram bots cannot read messages sent by other bots, and the Bot API does not expose group chat history. Because of that, the review bot primarily verifies the news bot through the `data/latest_news_post.json` receipt generated by `news_bot.py`. GitHub Actions uploads this receipt from the news workflow and downloads it in the review workflow.

## GitHub Actions

`daily_news.yml` runs at `03:00 UTC`, which is `11:00 AM Singapore time`.
`daily_review.yml` runs at `03:10 UTC`, which is `11:10 AM Singapore time`.
